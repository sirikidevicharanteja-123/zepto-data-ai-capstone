# Zepto Capstone Project

This repository contains a complete data and AI project divided into three modules.

## Modules

### 1. Data Pipeline
Web scraping, data cleaning, SQLite database integration, and SQL queries.

### 2. Analytics
Exploratory Data Analysis and machine learning.

### 3. Support Assistant
An AI-powered support assistant using document retrieval and language models.
